# Sales Data Analysis Using Python

## 1. Project Overview

This project focuses on analyzing retail sales data using Python. The main objective is to understand sales performance, customer preferences, product demand, and business trends.

## 2. Project Objectives

- Understand and explore raw sales data.
- Clean and preprocess the dataset.
- Handle missing values and duplicate records.
- Perform Exploratory Data Analysis (EDA).
- Analyze product-wise and city-wise sales.
- Identify customer purchasing patterns.
- Create a sales dashboard using Matplotlib.
- Generate meaningful business insights.

## 3. Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## 4. Dataset Information

The dataset contains retail sales information with the following columns:

- Order_ID
- Order_Date
- Customer_Name
- City
- Product
- Category
- Quantity
- Unit_Price
- Discount
- Payment_Mode

## 5. Project Workflow

### Data Understanding

- Checked dataset shape.
- Examined column names and data types.
- Identified missing values and duplicate records.

### Data Cleaning

- Handled missing values.
- Removed duplicate records.
- Corrected inconsistent text values.
- Converted date columns into datetime format.

### Exploratory Data Analysis

- Total Sales Analysis
- Product-wise Sales Analysis
- City-wise Sales Analysis
- Category-wise Sales Analysis
- Payment Mode Analysis
- Monthly Orders Analysis
- Top Customers Analysis

### Data Visualization

Created visualizations using Matplotlib to understand sales trends and patterns.
